# Identidad visual

Símbolo original generado con la herramienta imagegen de OpenAI para esta entrega; no es una descarga del catálogo mostrado como referencia por el usuario. PNG transparente conservado sin modificaciones. Destino: `palimpsesto-symbol.png`. Uso: marca de cabecera, sello de portada y favicon; palabra Palimpsesto se presenta como texto HTML accesible.

Dirección de generación: símbolo compacto y plano de tres marcos/páginas superpuestos, evocando archivo fotográfico y palimpsesto; letra P sugerida en espacio negativo; detalle mínimo de sol y curva de fotografía; verde profundo #173D36, salvia #76AAA0, oro apagado #C69A62 y marfil #F4EBDD; fondo transparente; sin palabras, fechas, eslogan, mockup, marcas de agua ni efecto 3D. El logotipo de referencia sirvió para orientar temática, no para reproducir una marca concreta.

La interfaz utiliza papel cálido, verde bosque y acentos oro. El ejemplo de documento de portada es una composición sintética identificada, sin fotos privadas del dataset. La tipografía usa familias de sistema para funcionar sin descargas. `theme.css` aplica la nueva identidad sobre el layout de `style.css`.
