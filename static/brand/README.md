# Identidad visual

El símbolo de Palimpsesto se conserva en `palimpsesto-symbol.png`, con fondo transparente. Se generó con ayuda de una herramienta de IA de imágenes (ChatGPT) a partir de la idea del equipo, que definió el concepto y la paleta; el archivo conserva sus metadatos de procedencia C2PA. Se utiliza en cabecera, portada y favicon; el nombre se presenta como texto HTML accesible.

La interfaz utiliza papel cálido, verde bosque y acentos oro. El ejemplo de documento de portada es una composición sintética identificada, sin fotos privadas del dataset. La tipografía usa familias de sistema para funcionar sin descargas. `theme.css` aplica la nueva identidad sobre el layout de `style.css`.
