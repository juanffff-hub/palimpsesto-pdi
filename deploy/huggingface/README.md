# Palimpsesto

**Una nueva mirada. La misma pieza.** Asistente de procesamiento digital de imágenes que convierte la foto de celular de un manuscrito, un documento impreso o una pintura en una copia frontal y legible. El usuario confirma o corrige cada paso.

Proyecto final de Procesamiento Digital de Imágenes, Universidad Autónoma de Occidente (2026-2). Equipo: David Neira Conde, Juan Sebastián Gómez Muñoz y Juan Felipe Fajardo Valencia.

- Código, datos, resultados y documentación: https://github.com/juanffff-hub/palimpsesto-pdi
- Corre en CPU. Las fotos se procesan en memoria durante la sesión y no se guardan ni se usan para entrenar.
- Si el Space estuvo un tiempo sin visitas, la primera carga tarda uno o dos minutos mientras despierta.
